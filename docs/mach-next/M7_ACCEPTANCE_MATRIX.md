Rules for this matrix:
- **Status** is `NOT RUN` unless a test or real run that already exists at `106f4d3` shows the expected outcome,
  in which case it is `PASS (existing: <where>)`. Nothing was run to fill this version. A `PASS (existing)` must
  be re-confirmed at the candidate commit; the **Evidence location** column stays blank until a row is run for M7.
- **Kind** is exactly one of: Unit · Integration · Browser end-to-end · Controlled live Factory execution · Real
  multi-machine test · Mocked enterprise integration · Manual inspection. A test with a stand-in `gh` is never a
  real enterprise test; a run with several clones on one Mac is never a multi-machine test.
- **Needs** marks rows that local simulation cannot complete: **2M** = a second physical machine; **GHEC** = a
  real GitHub Enterprise organisation (or at least a real GitHub repository with branch protection); **TAG** = a
  published, tagged release.
- **Area** cites the mandatory scenario of `DELIVERY_PLAN.md` (`DP-n`) and/or the brief's Phase 10 list (`A-n`).
- Real runs RR-M5, RR-M62, RR-M65, RR-L1, RR-L2 are defined in `M7_READINESS_INVENTORY.md`. All were on one Mac,
  with a local bare origin and a stand-in `gh`.
